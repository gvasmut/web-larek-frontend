# Проектная работа "Веб-ларек"
## Описание проекта

Проект представляет собой интернет-магазин с каталогом товаров. Пользователь может просматривать каталог товаров, выбрать отдельный товар для детального просмотра, добавлять товары в корзину и удалять их при необходимости. Пользователь также может просматривать список товаров в корзине (содержимое корзины) с их общей стоимостью. Для оформления заказа предусмотрены формы ввода данных: форма доставки и форма контактов. После успешного оформления заказа отображается уведомление об оформлении заказа.

Стек: HTML, SCSS, TS, Webpack

Структура проекта:
- src/ — исходные файлы проекта
- src/components/ — папка с JS компонентами
- src/components/base/ — папка с базовым кодом

Важные файлы:
- src/pages/index.html — HTML-файл главной страницы
- src/types/index.ts — файл с типами
- src/index.ts — точка входа приложения
- src/scss/styles.scss — корневой файл стилей
- src/utils/constants.ts — файл с константами
- src/utils/utils.ts — файл с утилитами

## Данные и типы данных используемые в модели (описание интерфейсов)
#### IProductItem
Продукт - определяет данные для описания товара (информация о продукте):
```
interface IProductItem {
  id: string,
  description: string,
  image: string,
  title: string,
  category: string,
  price: number|null;
}
```
#### IOrderData
Заказ - информация для формирования заказа

```
interface IOrderData {
  address: string,
  email: string,
  phone: string,
  payment: string,
  total:number,
  items:string[]
}
```
#### IProductList
Список товаров - информация для вывода товаров на страницу

```
interface IProductList {
	items: IProductItem[];
	getProduct(id: string): IProductItem;
}
```
#### IBasket
Корзина - информация о товарах в корзине
```
interface IBasket {
	items: IProductItem[];
	totalPrice: number;
	addProduct(product: IProductItem): void;
	deleteProduct(productId: string): void;
	cleanBasket(): void;
  checkIdInBasket(id: string): boolean
}
```

#### TOrderDeliveryData
Данные для формы доставки заказа - информация для формы с выбором способа оплаты и адреса доставки 
```
type TOrderDeliveryData = Pick<IUserForm, 'payment'|'address'>
```

#### TOrderUserData
Данные для формы с контактными данными - информация пользователя для заказа: телефон и почта 
```
type TOrderUserData = Pick<IOrderData, 'phone'|'email'>
```

## Архитектура приложения

Проект имеет MVP архитектуру. Код приложения разделен на слои согласно парадигме MVP:

 - слой данных, отвечает за хранение и изменение данных;
 - слой представления, отвечает за отображение данных на странице;
 - презентер, отвечает за связь представления и данных.
---
### Базовый код
#### Класс Арі
  Содержит в себе базовую логику отправки запросов. В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

***Методы***
 - `get` выполняет GET запрос на переданный в параметрах эндпоинт и возвращает промис с объектом, которым ответил сервер
 - `post` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется POST запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.
 - `handleResponse` - обрабатывает ответ, возвращает JSON, либо выбрасывает ошибку.

#### Класс EventEmitter

Брокер событий позволяет отправлять события и подписываться на события, происходящие в системе. Класс используется в презентере для обработки событий и в слоях приложения для генерации событий.
Основные методы, реализуемые классом описаны интерфейсом `IEvents:

- `on` - установить обработчик на событие;
- `off` - снять обработчик с события;
- `emit` - инициировать событие с данными;
- `onAll` - слушать все события;
- `offAll` - cбросить все обработчики;
- `trigger` - cделать коллбек триггер, генерирующий событие при вызове.

#### Класс Component

Базовый класс, предоставляющий общие методы для управления DOM-элементами и отрисовки интерфейса. Используется как родительский класс для всех визуальных компонентов (карточки товаров, формы, модальные окна и т.д.). 

***Конструктор***

Конструктор принимает HTML-контейнер. Класс создаёт экземпляр компонента на основе переданного HTML-контейнера.
`constructor(protected readonly container: HTMLElement)`

***Методы***
 - `toggleClass(element: HTMLElement, className: string, force?: boolean)` - переключатель классов. Добавляет или удаляет CSS-класс у элемента;
 - `protected setText(element: HTMLElement, value: unknown)` - установить текстовое содержимое элемента;
 - `setDisabled (element: HTMLElement, state: boolean)` - сменить статус блокировки. Включает или отключает элемент (например, кнопку);
 - `protected setHidden(element: HTMLElement)` - скрывает элемент;
 - `protected setVisible(element: HTMLElement)` - отображает элемент;
 - `protected setImage(element: HTMLImageElement, src: string, alt?: string)` - устанавливает изображение с алтернативным текстом;
 - `render(data?: Partial<T>): HTMLElement` - обновляет свойства экземпляра данными и возвращает корневой DOM-элемент компонента. Используется для отрисовки компонента в интерфейсе.

#### Класс LarekAPI
Специализированный API-класс для проекта web-larek. Он расширяет класс api для работы с сервером, добавляя методы для получения списка товаров, получения отдельного товара и отправки заказа. Также он автоматически дополняет пути к изображениям с помощью CDN-адреса.\
\
***Поля класса***
 - `readonly cdn: string` - путь для загрузки изображений\

***Конструктор***

Конструктор - принимает cdn для загрузки изображений, основной адрес сервера и дополнительные настройки запроса(например, заголовки).
`constructor(cdn: string, baseUrl: string, options?: RequestInit)`

***Методы***
- `getProductList: Promise<IProductItem[]>` - метод для получения и обработки списка товаров;
- `getProduct: Promise<IProductItem>` - метод для получения и обработки данных одного товара;
- `orderProduct: Promise<IOrderResult>` - принимает объект с данными заказа и отправляет заказ на сервер.

### Слой представления 
Все классы представления отвечают за отображение внутри контейнера (DOM - элементов) передаваемых в них данных.
#### Класс Form
Form<T> - обобщенный класс (компонент формы), который отвечает за состояние формы, обрабатывает (показывает) ошибки и инициализирует событие по кнопке submit. Наследует базовый функционал от класса Component.

***Поля класса***
 - `_submit: HTMLButtonElement` -  кнопка отправки формы;
 - `_errors: HTMLElement` -  контейнер для отображения ошибок.

***Конструктор***

Конструктор класса принимает клонированный из шаблона контейнер формы и инстант брокера событий
  - `constructor(container: HTMLFormElement, events: IEvents)`.

***Методы класса***
 - `set valid(value: boolean)` - изменяет состояние кнопки отправки; 
 - `set errors(value: string)` - принимает строку ошибок и обновляет контейнер для ошибок, устанавливая текст;
 - `onInputChange(field: keyof T, value: string)` - вызывается при изменении любого поля. Публикует событие изменения конкретного поля с его новым значением;
 - `render(state: Partial<T> & IFormState)` - подготавливает контейнер с актуальным состоянием и возвращает его, присваивает значения полям, переключает кнопку в зависимости от валидности.

#### Класс Modal
Modal - служит для представления модальных окон и выполнения общих функций: открытие и закрытие модальных окон. Наследует базовый функционал от класса Component.

***Поля класса***
 - `_closeButton: HTMLButtonElement` - кнопка закрытия модального окна;
 - `_content: HTMLElement` - контейнер для отображения содержимого модального окна.

***Конструктор***

Конструктор класса принимает клонированный из шаблона контейнер модального окна (HTML-элемент) и инстант брокера событий. Находит внутри контейнера кнопку закрытия и блок для контента, a также назначает обработчики: закрытие модалки по клику на кнопку закрытия и по фону вне модального окна, по клику на само модальное окно (контент модалки) предотвращается закрытие.
  - `constructor(container: HTMLElement, protected events: IEvents)`

***Методы класса***
 - `set content(value: HTMLElement)` - определяет содержимое модального окна;
 - `open()` - открытие модального окна;
 - `close()` - закрытие модального окна;
 - `render(data: IModalData): HTMLElement` - подготавливает контейнер модального окна с переданным содержимым и возвращает его.

 - `productCategory: HTMLElement` -  элемент категории товара.

***Конструктор***

Конструктор класса принимает клонированный из шаблона контейнер элемента карточки товара. Находит элемент изображения и категории, добавляется обработчик события по клику на карточку товара.
 - `constructor(container: HTMLFormElement, events: IEvents)`

***Методы класса***
 - `set image(value:string)` - обновляет изображение товара;
 - `set category (value:string)` - устанавливает текст категории, присваивает CSS-класс на основе категории (с помощью CategoryClassMap).

#### Класс ProductItemModal
ProductItem отвечает за отображение товара в модальном окне для показа детальной информации о товаре. Класс расширяет класс Product и добавляет изображение, категорию товара, описание и кнопку покупки к базовому отображению товара в классе Product.

***Поля класса***
 - `productImage: HTMLImageElement` - элемент изображения товара;
 - `productCategory: HTMLElement` - элемент категории товара;
 - `productDescription: HTMLImageElement` - элемент описания товара;
 - `productBtn: HTMLButtonElement` - элемент кнопки "В корзину".

***Конструктор***

Конструктор класса принимает клонированный из шаблона контейнер элемента карточки товара в модальном окне. Находит элементы: изображения, категории, описания, кнопки. Добавляет обработчик события по клику на кнопку.
 - `constructor(protected container: HTMLTemplateElement, events: IEvents) `

***Методы класса***
 - `set image(value:string)` - обновляет изображение товара;
 - `set category (value:string)` - устанавливает текст категории, присваивает CSS-класс на основе категории (с помощью CategoryClassMap);
 - `set description(value: string)` - обновляет описание товара;
 - `set inBasket(value: boolean)` - управляет состоянием кнопки: если товар в корзине делает кнопку неактивной и меняет текст кнопки на "Уже в корзине", если товара в корзине нет - кнопка остается активной с текстом "В корзину".

### Слой коммуникаций (Presenter)
#### Взаимодействие компонентов
Код, описывающий взаимодействие представления и данных между собой находится в файле `index.ts`, выполняющем роль презентера.\
Взаимодействие осуществляется за счет событий генерируемых с помощью брокера событий `EventEmitter` и обработчиков этих событий, описанных в `index.ts`\
В `index.ts` сначала создаются экземпляры всех необходимых классов, а затем настраивается обработка событий.

*Пример взаимодействия компонентов:*\
Пользователь открывает или обновляет страницу, выполняется запрос на сервер с помощью методов класса `LarekAPI`. После успешной загрузки данных и их обработки приложение инициирует событие `initialData:loaded`. С помощью `EventEmitter` подписываемся на событие `initialData:loaded`. При срабатывании события обращаемся к необходимым данным модели с помощью класса `ProductsListData`. Для каждого элемента массива данных создаётся карточка товара с помощью класса `ProductItem`. C помощью класса `Page` готовые карточки выводятся на страницу. Дополнительные элементы интерфейса главной страницы управляются через класс `Page`.



#### События

*События изменения данных (генерируются классами моделями данных):*\
`initialData:loaded` - продукты получены с сервера и готовы к отображению;\
`form:deliveryErrors:change` - обновление ошибок формы доставки/оплаты + валидация;\
`form:contactErrors:change` - обновление ошибок формы контактов + валидация;\
`product:clean` - очистка корзины после успешной покупки (сброс счётчика товаров);\
`product:add` - продукт добавлен в корзину;\
`product:remove` - продукт удален из корзины;\
`products: set` - получение списка продуктов;\
`basket:updated` - обновление корзины.

*События, возникающие при взаимодействии пользователя с интерфейсом (генерируются классами, отвечающими за представление):*\
`order:open` -  открытие формы заказа (доставка и оплата);\
`order.{field}:change` - изменение поля формы заказа доставки/оплаты;\
`contacts.{field}:change` - изменение поля формы контактов (телефон/почта);\
`order:submit` - подтверждение формы заказа доставки, открывается контактная форма;\
`contacts:submit` - подтверждение формы контактов - отправка заказа;\
`modal:open` - модальное окно открыто;\
`modal:close` - модальное окно закрыто;\
`basket:open` - открытие модального окна корзины с отображением товаров;\
`product:delete` - удаление продукта из корзины, обновление корзины и счетчика корзины;\
`product:select` - выбор продукта для отображения в модальном окне с подробностями о продукте;\
`product:buy` - товар куплен (добавлен в корзину и обновлен счетчик).
